# Third-party data and code notices

## Forever Atlas / AtlasLootClassic

The dungeon and raid loot data for the Forever-specific content is cross-checked
against the Forever Atlas project, release 1.0.53. Forever Atlas is a WoW
Forever fork of AtlasLootClassic and is released under the GNU General Public
License, version 2.

Project page: https://www.curseforge.com/wow/addons/forever-atlas

This project does not bundle the Forever Atlas addon or its UI. It uses the
published loot-table information as a reviewed data source and keeps the
Lootified Continued implementation separate. Any future direct code or data
redistribution from Forever Atlas must retain its GPL-2.0 license and the
original attribution.

## ForeverDB

Current item, quest, and dungeon catalog snapshots are generated from
https://foreverdb.net/ and credited in the addon help panel. The API key is
never stored in this repository.
