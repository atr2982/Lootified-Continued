# Lootified Continued

A community-maintained continuation of Lootified for WoW: Forever. It combines dungeon bosses and loot, dungeon quest chains, open-world drops, and level-aware gear recommendations in one English-only addon.

This continuation is maintained by atr2982 and preserves the original GPL-3.0 license and notices. It is independent of the original author's website and Discord support channel. The project data is maintained specifically for the Forever client.
