# Lootified Continued

A community maintained continuation of Lootified for World of Warcraft: Forever. It brings dungeon bosses and loot, dungeon quests and their chains, quest and world-map pins, open world drops, and level aware gear recommendations into one addon. This continuation uses English text and percent based stat weights.

Maintained by atr2982. Based on the original Lootified addon by Alen, under GPL-3.0. This repository preserves the original license and notices and marks the continuation as modified. It is independent of the original author's website and Discord support channel.

This is a public continuation project for personal use and collaboration.

## Data status

The local installation and repository data are refreshed against Forever client build 1.60.1.70862 using `/lf collect`. The packaged snapshot combines client-collected facts with refreshed ForeverDB catalog and dungeon-detail data, the latest verified Forever Atlas 1.0.53 dungeon tables, and the latest accessible Forever-specific BiS guide snapshot. The published BiS guide pages currently identify build 1.60.1.70790, so those guide picks are preserved until a newer Forever-specific guide export is available. Personal account collection data is excluded from this public repository. Any content that Forever sources explicitly mark as sealed, pending, or unverified remains labeled that way rather than being guessed. A source's Classic data must still be distinguished from observations in Forever.
